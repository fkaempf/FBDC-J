# CLAUDE.md — FBDC-J

FBDC-J (FlyBowlDataCapture-Jefferis) is the Jefferis-lab fork of
`kristinbranson/FlyBowlDataCapture`. MATLAB data-acquisition software for
the FlyDisco / FlyBowl arena.

## Local additions

- `TeensyLEDControl/` — selectable Teensy LED-controller firmware
  (`flybowl2015` vs `rgb_cmdarduino`), so the same code drives boards
  flashed with either the old or the new controller software. See its
  README.
